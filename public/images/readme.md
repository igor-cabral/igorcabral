# Imagens do site — igor cabral.

## Marca
- `/public/images/brand/logo-white.png` — logo oficial convertida para fundo transparente a partir da arte fornecida. Não substitua sem necessidade.

## Perfil
- `/public/images/profile/igor-cabral.jpg` — foto real do Igor, 1000×1200px ou maior, preferencialmente vertical. A página Sobre atualmente usa uma composição tipográfica e pode receber a foto quando você quiser.

## Portfólio
Os arquivos `barbearia-conceito.svg`, `restaurante-conceito.svg` e `servico-conceito.svg` são **projetos conceituais**, não clientes reais. Eles servem para o site não ficar vazio enquanto o portfólio real é construído. Quando houver trabalhos reais, crie os projetos reais pelo editor (ABRIR-EDITOR) e exclua os conceituais. As fotos enviadas pelo editor são salvas em `/public/images/projects/<nome-do-projeto>/`.

## Sistema
- `/public/images/system/favicon.svg` — favicon.
- `/public/images/system/og-image.svg` — imagem para compartilhamento.

Sempre prefira imagens WebP/AVIF para fotografias reais e comprima-as antes do deploy.
